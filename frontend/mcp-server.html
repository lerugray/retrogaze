// HOW IT WORKS

YOUR CLAUDE. OUR CONSTRAINTS.

Retrogaze's MCP server is a set of tools that Claude calls for classic console expertise. You tell Claude what to draw. Claude asks Retrogaze for the right palette, proportions, and drawing rules for your target console. Then Claude draws it in Aseprite using pixel-mcp. The result is a native .aseprite file with editable layers, correct palettes, and hardware-validated constraints.

  1. Ask Claude to draw a sprite. "Draw a 16x16 mid-era NES knight with a sword."
  2. Claude calls Retrogaze for console expertise. Gets the right palette and drawing rules for your target console.
  3. Claude draws it in Aseprite via pixel-mcp. Every pixel placed deliberately, validated against real hardware specs.
  4. Result: a hardware-authentic sprite in native .aseprite format, ready to edit or export.

// INSTALL

COPY. PASTE. DRAW.

Retrogaze's MCP server runs from source. Clone the repo, then run cd mcp-server && npm install && npm run build and use the path to dist/index.js in your MCP config. Point RETROGAZE_API_URL at your local or self-hosted Retrogaze API (default http://localhost:8000). No key or paid unlock required.

CLAUDE DESKTOP 
{
  "mcpServers": {
    "retrogaze": {
      "command": "node",
      "args": ["/path/to/retrogaze/mcp-server/dist/index.js"],
      "env": {
        "RETROGAZE_API_URL": "http://localhost:8000"
      }
    }
  }
}
CLAUDE CODE (.mcp.json) 
{
  "mcpServers": {

You'll also need Aseprite and pixel-mcp installed for the drawing tools. Retrogaze provides the constraint intelligence; pixel-mcp provides the Aseprite brushes.

// YOUR MODEL, YOUR COST

BRING YOUR OWN MODEL

You use your own API key. Retrogaze doesn't make AI calls on your behalf: your model makes the creative decisions, and Retrogaze provides the console expertise. You control the model and the cost.

Claude is tested and recommended. Sonnet is the practical choice: it clears the quality bar on all eras at ~5x less cost than Opus. Opus gives a half-grade quality premium. Haiku works for retro and early eras.

The MCP server is free and open source. All consoles and eras are available in the open-source build.

OTHER MODELS

The tools are model-agnostic by design: any LLM with MCP tool-use support can call them. GPT, Gemini, local models. The constraint intelligence comes from Retrogaze, not from the model.

We're looking for users willing to test non-Claude models and report quality results. If you want to help us expand model support, open an issue on GitHub with your results.

Interested? Open an issue and mention "multi-model testing" when you reach out.
