FREE & OPEN SOURCE

OCT 2026 FEATURE
  • No accounts: generate on the hosted demo without signing in
  • No payments: Retrogaze is free; run it yourself with your own fal.ai key
  • MIT license: fork, improve, and contribute on GitHub
// APRIL 2026

MULTI-CONSOLE SUPPORT

APR 8 FEATURE
  • 7 classic systems: generate sprites for NES, SNES, Sega Genesis, Game Boy, Game Boy Color, Commodore 64, and PC Engine in the app (Game Boy Pocket is a beta system available through the API and MCP)
  • Console-aware enforcement: palette remapping, tile limits, and color constraints match each console's real hardware
  • Console selector in the UI: pick your target console before generating
  • Era-appropriate styling: each console gets generation guidance tuned to its era and aesthetic
  • Smart palette allocation for consoles without fixed palettes (Genesis, SNES, GBC, PC Engine, C64)

ETHICS & ARTIST CREDITS

APR 8
  • 34 artists credited across 6 consoles on the ethics page
  • Credits link to original work where possible

MCP SERVER

APR 7 FEATURE
  • MCP server API: generate, list, and manage sprites programmatically
  • Local open-source MCP: point at your own Retrogaze API with RETROGAZE_API_URL
  • Multi-console support: TypeScript and Python clients for all classic systems, including Game Boy Pocket (beta)

SECURITY & STABILITY

APR 7 SECURITY
  • MCP server security hardening
  • Pre-deploy security audit and accessibility pass
  • Stability improvements

ASEPRITE GENERATION MODE

APR 6 FEATURE
  • Native Aseprite drawing: sprites drawn directly in Aseprite, palette-compliant from the start
  • Era-appropriate techniques: drawing tools and styles match the period you're targeting
  • Runs locally: requires Aseprite installed on your machine

ANIMATIONS

APR 5 FEATURE
  • 6 animation types: walk, attack, death, cast, idle, and jump
  • 4-frame spritesheets with zero palette drift: consistent character identity across all frames

// EARLIER

CORE FEATURES

FEB - MAR 2026
  • AI sprite generation: describe what you want, get hardware-accurate pixel art
  • 4 NES eras: retro (1978-83), early (1983-84), mid (1985-86), late (1987+)
  • Multi-directional sprites: front, right, back, left views with consistent character identity
  • Palette lock: force specific console colors before generating
  • Reference image upload: style-guided generation from an existing sprite
  • Tileset generation: full 9-tile sets with palette consistency
  • Spritesheet generation with animation frames
  • Real hardware validation: every sprite is checked against actual console constraints before delivery
  • Seed support for near-reproducible output
