// HOW TO PLAY

THREE STEPS. NO TUTORIALS.

01 DESCRIBE

Type what you need. Character, enemy, item, tile, tileset, UI element. Specify the era, mood, pose. Plain English is fine.

02 GENERATE

AI builds it inside real hardware constraints: the actual palettes, tile limits, and sprite rules of the console you're targeting. No lookalike approximations.

03 EXPORT

Download PNG, sprite sheets, atlas JSON, or palette files for your engine. Drop it into Unity, Godot, GameMaker, or your homebrew toolkit and go.

// FEATURE SELECT

WHAT YOU GET

🗂

9 ASSET TYPES

Characters, enemies, items, tiles, tilesets, UI elements, sprite sheets, directional walking sets, and UI frames. One tool covers your whole retro game.

📅

CONSOLE SELECT

7 classic systems in the app, each with their own hardware constraints enforced: NES, SNES, Sega Genesis, Game Boy, Game Boy Color, Commodore 64, and PC Engine. Game Boy Pocket is also available in beta through the API and MCP server.

🎨

TRUE HARDWARE CONSTRAINTS

Real console palettes. Real hardware limits. Every constraint enforced the way the actual hardware did it. Not a Photoshop filter.

🔒

PALETTE LOCK

Pick your exact colors from the console's real palette. Every asset shares the same locked palette: sprites, tiles, and UI all stay consistent across your whole game.

▶

SPRITE SHEETS

Walk, idle, and attack cycles generated as a single sheet with automatic frame slicing. Ready to import into your engine's animation controller.

📎

REFERENCE UPLOAD

Got a sketch on graph paper? A rough mockup? Upload it and the generator uses it as a style and layout reference. Your vision, the console's rules. Self-hosted only: the free demo does not accept uploads.

🔍

SCALED EXPORT

Export at 1x through 8x with nearest-neighbor scaling. Native pixels for your engine, zoomed versions for mockups, marketing, or documentation.

🎯

4 VARIATIONS

Self-hosted feature. When you run Retrogaze yourself, generate 4 candidates at once and pick the best, then hit "More Like This" to iterate on a style you like. The free demo makes one image per request and does not offer either. Fast convergence on exactly the sprite you need.

🗃

ATLAS JSON

Sprite sheets export with TexturePacker-compatible JSON. Frame coordinates, durations, and pivot points ready for Godot, Unity, and GameMaker.

📋

PALETTE TOOLS

Export palettes as GPL, hex, or PAL files for Aseprite, GIMP, or your custom tools. Lock colors from the console's real palette: keep your whole game consistent.

💾

PROMPT TEMPLATES

Save full generation configs: description, asset type, era, palette, every setting. One click to reload your setup. Build a library of presets for your project.

🖥

MCP SERVER

Bring your own Claude model and draw sprites natively in Aseprite via MCP tools. Hardware constraint intelligence for every supported console. Learn more →
